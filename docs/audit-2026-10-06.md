# Audit and research — October 6, 2026

## Scope and product decision

Audited default branch `main` at commit
[`10bb8b88f912131c00f68147e5588cb6fdc65492`](https://github.com/kaji-maker/Parliament_Watch/commit/10bb8b88f912131c00f68147e5588cb6fdc65492).
The owner selected a public citizen portal in Nepali and English, with verified
MP directory, attendance and bills first, and asset declarations later.

The existing FastAPI/PostgreSQL/Next.js stack is retained. Actual frontend
versions are Next.js 16.2.9 and React 19.2.4; the old README was stale.

## Findings in the audited revision

| Severity | Evidence | Consequence |
| --- | --- | --- |
| Critical | `backend/scrapers/utils.py:64` generates metrics, speeches, pledges and assets from names. | Invented facts can be attributed to real people. |
| Critical | `backend/main.py:124` uses generated ledgers/transcripts for live profiles too. | A live identity label masks unsupported associated facts. |
| Critical | `frontend/src/app/DashboardClient.tsx:230` substitutes mocks on empty/failed initial data. | Outages can look like valid political records. |
| Critical | `backend/scrapers/cron_worker.py:185` treats absence of an absence mention as presence. | Unsupported attendance percentages. |
| High | Startup and recovery bulk-delete profiles and commit before replacements. | Restart can lose data or fail due to child foreign keys. |
| High | Public mutations/scraper trigger lack authentication; credentials are hardcoded. | Unauthorized changes, expensive triggers and exposed credentials. |
| High | Member slugifier removes Nepali names; parser guesses identity fields and substitutes by constituency. | Identity collisions and incorrect attribution. |
| High | Date failures become today's date; bill/attendance failures return mocks. | Fabricated dates, statuses and records. |
| Medium | Asset totals read different tables from generated asset ledgers. | Summary/detail mismatch; valuation/currency ambiguity. |
| Medium | Hardcoded Docker/browser URLs and development server containers. | Deployment fragility. |
| Medium | No migrations, tests or CI files in audited tree; inaccessible modal/card interactions. | Weak regression coverage and citizen usability. |

## Executed audit checks

- All nine Python files compiled successfully.
- Snapshot: 275 rows; 165 FPTP and 110 PR records; no duplicate names or FPTP
  constituency strings.
- Snapshot gender totals: 183 male / 92 female. Election Commission's published
  election report gives 179 / 96. Reconcile against source records; do not
  treat an exact row count as validation.
- Isolated generator probes for two fictional names produced attendance,
  sponsored-bill counts, speech text and assets.
- Two distinct Nepali names both slugified to an empty string.
- An unparseable date returned the execution day's date.
- Full frontend build, browser and PostgreSQL tests were not run during the
  audit: shell network proxy access prevented cloning/dependency retrieval.

## Source research

Research observation date: 2026-10-06. Browser results can contain cached pages;
they are not a live ingestion run or a documented API contract.

| Source | Observation | Decision |
| --- | --- | --- |
| [Digital Parliament](https://digital.parliament.gov.np/) | Public member, meeting and committee views already exist. | Add citizen explanations, evidence, history and coverage rather than merely copy the directory. |
| [Member profile](https://digital.parliament.gov.np/members/hari-prasad-bhusal) | Bilingual identity, membership history, attendance counts, committees and speech references. Partial attendance weighting is described. | Preserve reporting period and methodology; reconcile meeting records before recomputing summaries. |
| [Meeting 68](https://digital.parliament.gov.np/baithak-detail/dad53bc8-57e6-4f8a-9197-fd1dc1747fac) | Meeting-specific attendance is visible. | Candidate member-by-meeting evidence. |
| [Digital bills](https://digital.parliament.gov.np/bills) | Section says it is being prepared. | Do not assume this endpoint contains a usable registry. |
| [House bill registry](https://hr.parliament.gov.np/np/bills?type=state) | Bill rows indexed; direct retrieval intermittent. | Separate adapter and reviewed manual fallback. |
| [Election results](https://result.election.gov.np/) and [EC report](https://ebulletin.election.gov.np/2026/03/3043/) | Official result sources; report distinguishes 165 FPTP and 110 PR elected members. | Independent election verification, no personal FPTP votes invented for PR members. |
| [Asset release notice](https://opmcm.gov.np/content/508/press-release-regarding-disclosure-of-property-details/) | Notice exists; complete accessible MP declaration coverage was not established. | Source feasibility before asset implementation. |

No documented public API, complete reuse permission, or reliable HTML/JSON
extraction contract was established. These remain explicit validation tasks.

## Comparisons and later constraints

[Digital Pratikpashya](https://www.digitalpratipakshya.com/) advertises member,
bill, attendance and government-monitoring features. This is a workflow
comparison, not an endorsement of its accuracy.

[mySociety's register of interests](https://pages.mysociety.org/parl_register_interests/datasets/commons_rmfi/latest)
is a useful model for dated, categorized interests with stable member identifiers
and original-source links.

[Officially hosted corruption-law material](https://ciaa.gov.np/uploads/publicationsAndReports/re5oj0.pdf)
includes confidentiality provisions for submitted declarations. Filing is not the
same as public release. Phase 8 must establish current publication authority and
available documents; do not infer non-filing from missing public records.

[WCAG 2.2](https://www.w3.org/TR/WCAG22/) is the first-release accessibility target.
